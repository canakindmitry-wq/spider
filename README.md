# Симулятор Человека-паука

Браузерная HTML5-игра в жанре tycoon для платформы **Яндекс Игры**. Игрок живёт в комнате Питера Паркера: снимает фото, спасает город, улучшает костюм, камеру, блог и интерьер.

Рассчитана на детей 6–12 лет: один экран без перезагрузок, только клики/касания, крупные кнопки и русский текст.

## Как запустить локально

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:43124`).

Сборка для загрузки в Яндекс Игры:

```bash
npm run build
```

Папка `dist` — готовый архив: внутри `index.html` и ассеты с относительными путями (`base: './'`).

## Как играть

- **Ноутбук** — мини-игра фотографа: ловите объект в рамку и жмите «Снять».
- **Окно** — мини-игра героя: нажимайте на жителей и злодеев, пока идёт таймер.
- **Вешалка** — прокачка костюма (10 уровней) и скины.
- **Камера на столе** — прокачка камеры (10 уровней).
- **График** — пассивный доход (копится офлайн).
- **Коробка** — предметы для комнаты и отключение рекламы.
- **Стена** — коллекция редких кадров (до 6, каждый даёт +5% к фото).
- **Кубок** — достижения.
- **Телевизор** (после покупки) — ежедневный бонус 200 монет.

Энергии нет, играть можно бесконечно. Прогресс пишется в `localStorage`.

## Монетизация

Цены премиума **в рублях и в два раза ниже** исходных долларовых:

| Товар | Цена |
| --- | --- |
| Отключение рекламы | 99 ₽ |
| Золотой паук | 49 ₽ |
| Паук-рыцарь | 75 ₽ |
| Космический паук | 99 ₽ |
| Паук-невидимка | 75 ₽ |
| Радужный паук | 49 ₽ |

Скины за монеты тоже удешевлены вдвое (250–750 🪙).

Идентификаторы покупок для консоли Яндекс Игр:

- `disable_ads`
- `skin_gold`
- `skin_knight`
- `skin_cosmic`
- `skin_invisible`
- `skin_rainbow`

Без SDK (локальный запуск) реклама и покупки идут в тестовом режиме: короткая заглушка и подтверждение покупки.

## Стек

Чистый JavaScript (Vite), без Phaser. Графика — CSS, SVG и эмодзи. Звук — Web Audio API.
