# Симулятор Человека-паука

Браузерная HTML5-игра в жанре tycoon для **Яндекс Игр**. Игрок живёт в комнате Человека-паука: снимает фото, спасает город, улучшает костюм, камеру, блог и интерьер.

Для детей 6–12 лет: один экран без перезагрузок, только клики и касания, крупные кнопки, весь текст на русском.

## Как запустить локально

```bash
npm install
npm run dev
```

Откройте адрес Vite (по умолчанию `http://localhost:43124`).

Сборка архива для консоли Яндекс Игр:

```bash
npm run zip
```

Появится `spiderman-tycoon.zip`. Внутри — `index.html` и ассеты с относительными путями (`base: './'`). Шрифты Nunito упакованы в архив, внешних CDN нет.

Либо вручную:

```bash
npm run build
```

Папка `dist` — то же содержимое без zip.

## Как играть

- **Ноутбук** — мини-игра фотографа: поймайте объект в рамку и нажмите куда угодно (кнопка «Снять» тоже работает).
- **Окно** — мини-игра героя: нажимайте на жителей и злодеев, пока идёт таймер.
- **Шкаф / вешалка** — прокачка костюма (10 уровней) и скины за монеты. Купленный костюм надевается сам.
- **Кнопка ₽** — покупки за рубли: отключение рекламы и премиум-костюмы (тоже надеваются сразу).
- **Камера на столе** — прокачка камеры (10 уровней).
- **Блог** — пассивный доход (копится, даже когда вкладка закрыта). В меню видна максимальная сумма, которую можно накопить.
- **Коробка / кровать** — предметы для комнаты.
- **Стена** — коллекция редких кадров (до 6, каждый даёт +5% к фото).
- **Достижения** — награды за прогресс.
- **Телевизор** (после покупки) — бонус 200 монет раз в 7 минут.

Энергии нет. Прогресс пишется в `localStorage`, а в каталоге Яндекса ещё и в облако игрока.

## Яндекс Игры: что включить в консоли

1. Загрузите `spiderman-tycoon.zip`.
2. Включите **«Игра использует облачные сохранения»**.
3. Создайте таблицу лидеров с техническим именем **`coins`** (очки = всего заработано монет).
4. Добавьте покупки с этими ID (цены в рублях):

| ID | Товар | Цена |
| --- | --- | --- |
| `disable_ads` | Отключение рекламы | 99 ₽ |
| `skin_gold` | Золотой паук | 49 ₽ |
| `skin_knight` | Паук-рыцарь | 75 ₽ |
| `skin_cosmic` | Космический паук | 99 ₽ |
| `skin_invisible` | Паук-невидимка | 75 ₽ |
| `skin_rainbow` | Радужный паук | 49 ₽ |

Скины за монеты удешевлены вдвое (250–750 🪙).

SDK подключается как `/sdk.js` на серверах Яндекса (как требует модерация). Локально SDK не грузится: реклама и покупки идут тестовыми заглушками.

Игра вызывает `LoadingAPI.ready`, `GameplayAPI.start/stop`, полноэкранную и rewarded-рекламу, `Player.getData/setData`, `getPayments` и `getLeaderboards`.

## Стек

Чистый JavaScript (Vite), без Phaser. Графика — CSS, SVG и эмодзи. Звук — Web Audio API.
